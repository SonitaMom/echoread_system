Keyboard Shortcuts & Accessibility Navigation

EchoRead is designed from the ground up for blind and low-vision readers. You can control reading and navigation entirely through the keyboard without touching a mouse.

Action Shortcut Description
Play / Pause Reading Ctrl + Space Start or pause audio for current page
Stop Reading Escape or Ctrl+Shift+Space Stops reading immediately
Next Page Ctrl + → Advance to the next page
Previous Page Ctrl + ← Return to previous page
Rewind 10 Seconds ← (Left Arrow) Skip back 10 seconds in audio
Forward 10 Seconds → (Right Arrow) Skip forward 10 seconds in audio
Faster Speech Ctrl + ↑ Speed up reading voice
Slower Speech Ctrl + ↓ Slow down reading voice
Toggle Shortcuts Guide ? (Shift + /) Show or hide this modal
Open Help Page Ctrl + / Detailed user guide
